# PS2 Store v0.8

- Historico de downloads persistente em arquivo JSON no diretorio de suporte do aplicativo.
- Tela de historico com nome, data e local de salvamento.
- Deduplicacao de resultados de busca pelo repositorio de origem.
- Mensagem de erro HTTP mais clara.
- Testes unitarios do formato do historico.

## Limites

- Nao ha retomada de downloads interrompidos nesta versao.
- A busca continua restrita ao GitHub e nao certifica seguranca ou compatibilidade.
- Testes reais no Android e Linux permanecem necessarios.
