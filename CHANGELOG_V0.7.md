# PS2 Store v0.7 — qualidade da busca

- Pesquisa no GitHub preservada, com filtros heurísticos de relevância ao PS2.
- Classificação inicial em Emuladores, Arquivos, Launchers, Jogos homebrew e Utilitários.
- Ordenação por relevância, autor do repositório visível e pesquisa local incluindo autor/categoria.
- Testes unitários da classificação e relevância.
- Downloads continuam na pasta Downloads do sistema, sem alterações no fluxo existente.

**Limitações:** heurísticas podem excluir projetos legítimos e incluir projetos não compatíveis. Não existe verificação de executáveis, malware, licença, arquitetura ELF ou conteúdo de arquivos ZIP. Sempre conferir o repositório antes de executar arquivos no console. O GitHub impõe limites de API e a busca depende de conexão.
